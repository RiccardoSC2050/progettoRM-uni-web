# Documentazione progetto RK/MK

Questa cartella raccoglie la documentazione finale del progetto. I file sono stati organizzati per separare relazione, architettura, metodo di lavoro, requisiti e controlli finali.

## File disponibili

```text
docs/
├── README.md
├── RELAZIONE_PROGETTO.md
├── ARCHITETTURA.md
├── METODO_DI_LAVORO.md
├── UI_UX_E_RESPONSIVE.md
├── TEST_E_REVISIONE.md
└── REQUISITI.md
```

## Uso consigliato

- `RELAZIONE_PROGETTO.md` è il documento principale da usare per presentare il progetto.
- `ARCHITETTURA.md` descrive la struttura tecnica e il collegamento tra front-end, back-end e database.
- `METODO_DI_LAVORO.md` descrive come è stato distribuito il lavoro nel tempo, includendo call, GitHub e supporto dell'AI.
- `UI_UX_E_RESPONSIVE.md` raccoglie le scelte di interfaccia e responsive design.
- `TEST_E_REVISIONE.md` contiene la checklist di verifica.
- `REQUISITI.md` sintetizza i requisiti funzionali e tecnici.

- `ANALISI_LOGICA_SIM.md`: analisi del flusso CRUD SIM e del limite relativo alla scadenza futura.
