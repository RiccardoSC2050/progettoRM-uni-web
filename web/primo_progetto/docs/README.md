# Documentazione progetto RK/MK

Questa cartella raccoglie solo la documentazione finale utile alla consegna e alla comprensione tecnica del progetto.

## File disponibili

```text
docs/
├── README.md
├── RELAZIONE_PROGETTO.md
├── ARCHITETTURA.md
├── ANALISI_LOGICA_SIM.md
├── UI_UX_E_RESPONSIVE.md
├── TEST_E_REVISIONE.md
└── REQUISITI.md
```

## Uso consigliato

- `RELAZIONE_PROGETTO.md` è il documento principale da usare per presentare il progetto.
- `ARCHITETTURA.md` descrive la struttura tecnica e il collegamento tra front-end, back-end e database.
- `UI_UX_E_RESPONSIVE.md` raccoglie le scelte di interfaccia e responsive design.
- `TEST_E_REVISIONE.md` contiene la checklist di verifica.
- `REQUISITI.md` sintetizza i requisiti funzionali e tecnici.
- `ANALISI_LOGICA_SIM.md` descrive la logica applicativa delle SIM e delle transizioni di stato.
