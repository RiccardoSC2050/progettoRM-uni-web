Database di destinazione

Il database viene creato automaticamente. Se esiste già, viene ricreato da zero.

Seleziona un database per riutilizzarne il nome oppure eliminalo definitivamente.

Importazione ridotta

Il limite viene applicato separatamente a contratti, SIM attive, SIM disattive, SIM non attive e telefonate. Con il valore consigliato vengono scaricate al massimo 500 righe. Le SIM attive e le telefonate senza il relativo contratto nel campione vengono ignorate, così PostgreSQL resta coerente.
