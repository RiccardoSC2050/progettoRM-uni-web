# Progetto 1 - Telefonia

Struttura ordinata del progetto:

- `app/`: applicazione web PHP
- `docs/`: documentazione originale del progetto
- `data/excel/`: file Excel originale
- `data/csv/`: file CSV originali
- `.vscode/`: configurazione locale editor

Note organizzative:

- I file in `docs/`, `data/excel/` e `data/csv/` non sono stati modificati nel contenuto.
- I file duplicati `index.htm` e `index.html` dell'app sono stati rimossi per lasciare un solo entrypoint: `app/index.php`.
